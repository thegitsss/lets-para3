# Provider artwork

`clio-symbol.svg` and `clio-wordmark.svg` contain the unchanged SVG shapes published by Clio in its official website header. The wordmark includes Clio's own lettering; no proprietary font file is bundled. They identify LPC's Clio integration and are displayed separately from LPC's name and interface typography.

Retrieved November 2, 2026 from the SVG mask assets in https://www.clio.com/_astro/SiteHeader.BI-thJa4.css, linked by https://www.clio.com/.

Provider references:

- https://www.clio.com/about/brand-assets/
- https://brand.clio.com/guidelines/
- https://www.clio.com/about/brand-assets/clio-limited-brand-use-license/

The integration does not display a partner, certification, sponsorship or endorsement claim. Keep provider geometry and proportions intact when replacing the artwork with a future official version.
