# Paralegal Home state and source contract

Scope: the existing authenticated `paralegal-v2.html` Home, `home-view.mjs`, and a pure `home-model.mjs` presentation model. Existing backend rules and other destinations remain authoritative. This contract was recorded before implementing the replacement Home UI.

## Model boundary

`buildHomeModel(snapshot, { now, userId })` consumes the existing named `{ available, value, error }` source wrappers (optionally `state: loading|stale|restricted|error|unavailable`). It returns `today`, `sources`, `attention: { state, item, candidates }`, `activeWork: []`, `opportunities: { invitations, applications, recommendations }`, `deadlines: []`, `communications: { items, unreadCount, state, complete }`, `history: { metrics, state, href }`, `availability`, and `readiness: { profile, payout, items }`.

Rows have stable `id`, `title`, `status`, `label`, `href`, `actionLabel`, `deadline`, and `eventAt` where supported. Attention adds `kind`, `priority`, `detail`, and `groupId`. A missing date or event is empty/zero, never a fabricated recent event. No component independently decides eligibility or priority. Sources expose `state`, `available`, and `complete`. Missing sources are loading; rejected reads are unavailable/error/restricted; successful empty arrays are ready and empty. Stale sources cannot produce current protected records, financial values, or actions. Session/user mismatch clears every protected region. An explicit current profile with another role, a status other than approved, or disabled/deleted state likewise clears protected content even if the shell's earlier identity was approved.

## Deterministic attention

Only current authorized records enter the candidate set. The selection is presentation priority, not a lifecycle or response policy:

1. Verified pre-hiring request requiring the current applicant's action.
2. Past-due unresolved authoritative Matter deadline; then today's Matter deadline.
3. Recorded active-work update (label “Latest update”; no unseen/new claim).
4. Actionable invitation.
5. Recorded shortlisted/viewed application movement.
6. Upcoming authoritative Matter deadline, nearest first.
7. Unread communication awareness and active workspace continuation.
8. Recommendations.

Within a class: applicable deadline ascending (missing last), relevant event timestamp descending, stable record ID ascending. No endpoint completion order or incidental array order. One Matter group contributes only its highest candidate; the active list carries the full summary and attention carries the issue/action. Source failure never resolves to “You’re clear.” A known candidate can be shown with incomplete-source status; no candidate yields quiet only when all attention inputs are complete, otherwise loading/unavailable/restricted/stale. Private reminders are awareness, not an inferred unresolved business obligation.

## Revalidation and interaction contract

The existing Home cache TTL is 30 seconds and must be scoped to verified user and revision. Invalidate after confirmed availability/profile/payout/application/invitation/message/deadline/Matter changes using existing shell refresh, subscriptions and cross-tab paths. Logout, account change, session expiry or access loss clears protected state and invalidates pending requests; a late response cannot restore it. No confidential payload enters URL query parameters, general storage, telemetry, Assistant context or logs.

Route entry/retry and an interaction-safe refresh boundary recalculate the model. Background refresh must not replace a focused row, move a control under the pointer, close a dialog, discard typed availability input, steal focus or reset scroll. Existing destination flows own nontrivial mutations, pending states, idempotency and recoverable errors. Home opens their supported deep links. Details within Home reuse that same authority.

## Verification matrix and smallest unsupported extensions

`backend/tests/paralegalHomeModel.test.js` covers A–L model combinations, deterministic competing priorities, invalid/excluded records, terminal requests, matching/payout scoping, New York midnight/DST/date validity, local failures, stale snapshots, user mismatch, communication semantics, duplicate recommendations, and financial projection honesty. Browser coverage covers viewport/layout, actual destinations, availability duplicate submission/input retention, deferred refresh, retry and session boundaries. Existing paralegal V2 contracts remain regression gates; superseded aesthetic assertions require equivalent behavioral assertions, not skips.

Home summaries have no revision-request summary, reliable latest-file timestamp/read receipt, user-scoped last-visit marker, document/page progress, or payout bank-receipt event. Therefore Home shows only supplied latest-file/update metadata and honest workspace navigation. Richer revision urgency would require a narrowly authorized summary field in the dashboard projection, not N confidential workspace fetches. Complete calendar history would require explicit range/pagination or the existing Matter reminders view; no backend expansion is part of this change.
