# LPC documentation map

This index separates current launch authority from retained historical work. A historical audit, plan, checklist, or test result never overrides current source, the executable gates, or exact-candidate evidence.

## Current launch authority

- `../LAUNCH_CHECKLIST.md`: owner-facing pre-launch checklist and signoffs.
- `RELEASE_GATES.md`: executable and external stop-ship policy.
- `LAUNCH_CERTIFICATION_CURRENT.md`: current evidence snapshot and GO/NO-GO decision.
- `BROWSER_SUPPORT.md`: supported browser, device, viewport, accessibility, and manual-validation contract.
- `../ROLLBACK_PLAN.md`: four-service containment, rollback, reconciliation, and drill record.

## Current product and operating policy

- `LAUNCH_COMPLETION_PLAN.md`: execution index for finishing the full intended product in integrated workflow groups, with acceptance criteria and evidence states; does not replace launch authority.
- `LPC_PRODUCT_NORTH_STAR.md`: product and interaction principles.
- `LPC_AI_OPERATING_MANUAL.md`: current AI/operator capability boundaries.
- `LPC_ADMIN_DASHBOARD_GAP_AUDIT.md`: current admin and Control Room resolution record.
- `LPC_ROUTE_SECURITY_INVENTORY.md` and `LPC_ROUTE_SECURITY_PASS_EVIDENCE.md`: generated mutating-route inventory and its reproducible gate.
- `../backend/docs/production-operations.md`, `../backend/docs/incident-runner.md`, and `../backend/backup-recovery.md`: production topology, monitoring, incident, backup, and recovery contracts.
